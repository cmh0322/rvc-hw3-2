## Divergence and tests

Confirmed defect, severity medium: C13's startup prohibition is violated. Scenario: invoke Main and deliver zero Ticks; Forward is already sent to the motor. Consequence: an unrequested movement command precedes sensor evaluation and the first Tick. Actual physical movement/collision is not established. Minimal fix: remove initialization output, make Reset Movement Controller state-only as approved SD specifies, and update startup tests; preserve Tick-driven movement/cleaning. This overlaps C13 and should be deduplicated in the aggregate review.
