First resumed Forward Tick returns CLEAN_START instead of five CLEAN_POWER_UP Ticks. If D3 was paused at 2, only two powered Ticks resume instead of a fresh five. Both paths follow `movement_controller` state transitions (`src/movement_controller.c:27?60`) into `derive_movement_status`, then the timer and output path.
